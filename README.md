# Demo Trade

Учебная торговая симуляция для новичков. В репозитории находится одностраничное приложение на чистом HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` в браузере либо включите GitHub Pages для ветки `main`.

## Возможности

- виртуальный баланс USDT;
- BTC/USDT, ETH/USDT и SOL/USDT;
- динамический учебный график;
- рыночные и лимитные ордера;
- открытые позиции и нереализованный P/L;
- история сделок и сохранение состояния в браузере;
- сброс учебного аккаунта.

Все цены и средства являются учебными и не связаны с реальной биржей.
